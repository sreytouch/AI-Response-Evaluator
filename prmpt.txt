
Build a complete beginner-friendly full-stack project called AI Response Evaluator.

Goal

Create an application that demonstrates concepts related to:

* supervised fine-tuning
* human preference data
* RLHF
* reward modeling
* model evaluation
* instruction following
* response ranking
* iterative model improvement

The application should allow a user to enter a prompt, generate two different AI responses, compare them side by side, evaluate them using a rubric, select the better response, explain why it is better, and save that human preference data for later analysis.

This is an educational portfolio project. Do not implement real large-scale RLHF or PPO training. Instead, simulate the important workflow in a clear, understandable way.

Technology Stack

Use:

* Python
* Streamlit
* OpenAI API
* Pandas
* SQLite
* Matplotlib
* scikit-learn where useful
* python-dotenv
* pytest for basic tests

Keep the project simple enough for a beginner to understand.

Main Application Flow

The app should work like this:

1. User enters a prompt.
2. User can optionally specify constraints.
3. The application generates Response A.
4. The application generates Response B separately so the outputs differ.
5. Display both responses side by side.
6. Let the evaluator score each response.
7. Let the evaluator choose:
    * Response A is better
    * Response B is better
    * Tie
8. Ask the evaluator to provide a short rationale.
9. Save all data into SQLite.
10. Display evaluation statistics in a dashboard.
11. Allow exporting collected human-preference data to CSV.

Example Prompts

Include a page containing sample evaluation prompts such as:

* Explain gravity to a 7-year-old in no more than 3 sentences.
* Explain photosynthesis to a middle-school student using simple language and one example.
* Rewrite “Send me the report today” to sound more polite without changing the meaning.

Evaluation Rubric

Allow evaluators to score each response from 1 to 5 on:

1. Correctness
2. Instruction Following
3. Relevance
4. Clarity
5. Completeness
6. Style

Display short descriptions for every category.

For example:

Correctness:
Does the answer contain accurate information?

Instruction Following:
Did the answer satisfy all explicit user requirements?

Relevance:
Does the response stay focused on the request?

Clarity:
Is the response easy to understand?

Completeness:
Does it address all important parts of the request?

Style:
Is the tone and structure appropriate?

Calculate an overall average score for each response.
